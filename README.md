# FoxyVPN Android + FoxyKeygen

کلاینت غیررسمی Firefox VPN برای اندروید، به‌همراه سیستم «کلید حجمی» برای توزیع سهمیهٔ رایگان ۵۰ گیگابایتی یک اکانت فایرفاکس بین چند نفر.

## اجزا

| پوشه | توضیح |
|---|---|
| `android-app/` | اپ اصلی (FoxyVPN) — نسخهٔ کسانی که با کلید فعال‌سازی وصل می‌شوند |
| `keygen-app/` | اپ سازندهٔ کلید (FoxyKeygen) — فقط برای دارندهٔ اکانت |

APKهای آمادهٔ نصب در بخش [Releases](../../releases) موجود است.

## تغییرات نسخهٔ 2.1.0 (اپ اصلی) و 1.1.0 (کلیدساز)

- **باطل‌سازی فوری**: کلیدِ باطل‌شده دیگر اجازهٔ اتصال جدید نمی‌گیرد (چک در لحظهٔ اتصال) و در طول جلسه هر ۳۰ ثانیه یک‌بار چک می‌شود — قبلاً حداکثر ۶ دقیقه طول می‌کشید.
- **مصرف زندهٔ دقیق‌تر**: گزارش مصرف به داشبورد از هر ۳ دقیقه به هر ۳۰ ثانیه رسید؛ عدد کلیدساز و برنامهٔ اصلی حالا تقریباً هم‌خوان است و آخرین بایت هم هنگام قطع‌شدن گزارش می‌شود.
- **شمارش معکوس روزها**: برنامهٔ اصلی روی کارت اشتراک «N روز باقی‌مانده» را زنده نشان می‌دهد و هر روز کم می‌شود؛ کلیدساز هم برای هر کلید «N روز تا تمدید» می‌بیند.

## چطور کار می‌کند؟

1. دارندهٔ اکانت، **FoxyKeygen** را باز می‌کند و یک‌بار با ایمیل/رمز فایرفاکس خودش وارد می‌شود.
2. یک توکن GitHub با دسترسی Gist می‌سازد و در اپ وارد می‌کند (برای گزارش مصرف زنده).
3. برای هر نفر یک کلید می‌سازد: **نام + حجم (گیگ) + مدت (ساعت/روز/ماه)**.
4. دوستش فقط `FoxyVPN` را نصب می‌کند، کلید را می‌چسباند و مستقیم وصل می‌شود — بدون ایمیل/رمز/کد.
5. مصرف هر نفر روی گوشی خودش شمرده می‌شود و هر چند دقیقه به یک Gist مخفی گزارش می‌شود؛ سازندهٔ کلید آن را در تب «کلیدهای من» به‌صورت زنده می‌بیند و می‌تواند هر کلید را باطل کند.

## ساخت از سورس

```bash
# اپ اصلی
cd android-app
./gradlew assembleRelease   # یا gradle assembleRelease

# کلیدساز — کلید امضای Ed25519 از طریق پراپرتی گریدل تزریق می‌شود
# (کلید خصوصی عمداً در این ریپو منتشر نشده است)
cd keygen-app
gradle assembleRelease -PFOXY_PRIVATE_KEY=<base64-ed25519-private-key>
```

نکتهٔ امنیتی: کلید عمومی در `android-app` تعبیه شده و کلید خصوصی فقط باید نزد سازنده بماند. هر کس کلید خصوصی را داشته باشد می‌تواند کلیدهای حجمیِ دلخواه بسازد.
